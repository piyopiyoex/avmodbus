# ドキュメント

現在の使い方は [サンプル README](../README.md) を正とします。この `docs/` には、今後も維持する
設計判断、制約、代表的な実測結果だけを残します。

- [ロードマップ](roadmap.md) — 達成済みの範囲と、次の実験へ進む条件
- [既知の制約](limitations.md) — topology、delivery、recovery、用途の境界
- [検証結果](worklog/README.md) — Stage 0〜11 の代表値と失敗条件
- [設計判断記録](adr/README.md) — application と transport lifecycle の判断

個別の操作ログと完了済み計画書は Git の履歴で確認できます。同じ結果を複数ページへ転載せず、
実行方法はサンプル README、判断は ADR、実測値は検証結果へ集約します。
